🛡️ AdGuard VPN CLI — Шпаргалка

Краткое руководство по установке, настройке и работе с AdGuard VPN в Ubuntu (терминал).

📦 1. Установка

Официальный скрипт установки:

curl -s https://raw.githubusercontent.com/AdguardTeam/AdGuardVPNCLI/master/scripts/install.sh | sudo bash

После установки (если нужно автодополнение команд) добавьте в ~/.bashrc:

[ -s "/opt/adguardvpn_cli/bash-completion.sh" ] && \. "/opt/adguardvpn_cli/bash-completion.sh"

🔑 2. Авторизация (Вход)

Выполните команду:

adguardvpn-cli login
  • Терминал выдаст ссылку и код (действуют 30 минут).
  • Откройте ссылку в браузере на любом устройстве.
  • Введите код и подтвердите вход в аккаунт AdGuard.
  • В терминале появится сообщение Successfully Logged in.

⚙️ 3. Первоначальная настройка (при первом connect)

При первом запуске adguardvpn-cli connect система задаст 3 вопроса. Рекомендуемые ответы:

  • Set default routes in TUN mode? → y (весь трафик идет через VPN).
  • Allow AdGuard VPN to set system DNS? → n (безопаснее не менять DNS без необходимости).
  • Collect crash reports? → y или n (на ваше усмотрение).
Важно: При подключении/отключении система может запрашивать пароль sudo. Это нормально, так как VPN меняет сетевые маршруты.

🔌 4. Основные команды

Подключение и отключение

Команда Действие
adguardvpn-cli connect Подключиться к лучшему серверу (по умолчанию)
adguardvpn-cli disconnect Отключить VPN
adguardvpn-cli status Проверить текущий статус подключения

Выбор локации (сервера)

Посмотреть список доступных стран:

adguardvpn-cli list-locations

Подключиться к конкретной стране (например, Швеция):

adguardvpn-cli connect -l "Sweden"

Название локации нужно указывать точно так, как оно отображается в списке.

Управление аккаунтом

Команда Действие
adguardvpn-cli logout Выйти из аккаунта
adguardvpn-cli config Открыть настройки (изменить TUN, DNS и т.д.)

🛠️ 5. Решение проблем

  • Ошибка "Permission denied": Добавьте sudo перед командой, если она требует прав root.
  • Логи в терминале: Строки WARN и INFO при подключении — это нормально. Они показывают процесс поиска сервера.
  • Не работает интернет после отключения: Проверьте статус (adguardvpn-cli status). Если VPN выключен, но интернета нет — возможно, сбились маршруты. Попробуйте перезагрузить сеть: sudo systemctl restart NetworkManager.
